# Third-party software and sounds

Nothing below is stored in this repository. `aidaw kit install` (same as `plaindaw kit install`)
downloads the official release files into the app's own `kit/` folder, checks them against the
checksums pinned in `plaindaw/kit.py` / `plaindaw/kit_pins.json`, and records what it installed in
`kit/kit.json`. `kit/` is git-ignored. On Windows the kit always lives inside the AIDAW folder
(never under `C:\Program Files`; the installer refuses those paths). Override with `PLAINDAW_KIT`.

## Python and native dependencies

- pedalboard (GPL-3.0), used to host VST3 plugins.
- CLAP headers (MIT), included under `plaindaw/native/third_party/clap-include`.
- NumPy, SciPy (BSD-3-Clause), soundfile (BSD-3-Clause, wraps libsndfile LGPL-2.1), mido (MIT).
- ffmpeg (LGPL/GPL, optional, not bundled) for MP3/OGG/Opus/M4A.
- Test-only: pytest, pyloudnorm, mcp, playwright.
